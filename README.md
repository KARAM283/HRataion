# HRration — HR Manager

Bilingual (Arabic / English) human-resources workspace built with React, Vite, TypeScript and Supabase.

## Local setup

1. Install Node.js LTS.
2. Run `npm install`.
3. Copy `.env.example` to `.env.local`.
4. Set:
   - `VITE_SUPABASE_URL`: Supabase Project URL
   - `VITE_SUPABASE_ANON_KEY`: Supabase publishable key (or legacy anon key)
5. Run `npm run dev`.

## Production build

- Build command: `npm run build`
- Output directory: `dist`

## Cloudflare Pages

Connect this repository to Cloudflare Pages using the Vite settings above. Add the two environment variables for both Production and Preview environments before deploying.

Never put a Supabase secret/service_role key in a browser application or commit credentials to Git.


## Employee login and attendance setup

1. Run the SQL migration in `supabase/migrations/20261122130000_employee_accounts_attendance.sql` in the Supabase SQL Editor.
2. Install or use the Supabase CLI, sign in, and link this project:
   ```bash
   npx supabase login
   npx supabase link --project-ref wnuestxmvscvgflemnem
   npx supabase functions deploy admin-create-employee --use-api
   ```
3. The Edge Function uses the Supabase-provided `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY` environment variables. Never expose the service-role key in frontend variables.
4. Deploy the Vite app to Cloudflare after the GitHub changes are built.

Employee accounts use the internal login email `<username>@blueline.local`. The administrator creates each account from the Accounts screen and links it to an existing employee record. Employees receive an attendance-only screen; check-in and check-out timestamps are generated by database functions using Baghdad local date.
